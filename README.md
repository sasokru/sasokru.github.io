# Web Programming Project: Digital Health Professional Page 

This repository was created as part of my Web Programming course at Leuphana University Lüneburg in Summer Semester 2026, in which we started at zero and learned how to create 
websites using HTML and CSS as design language.


## Content

For this assignment, I chose a topic related to my professional goal of entering the digital health world.
The website introduces myself as a person and a short CV, my university project the prototype of drip.py and an essay I wrote on AI in medicine. I also included a digital health news page as information and hot topic overview.


## Learning Focus

Through this project, I am learning:

* how to structure content with HTML (headings, lists, sections)
* how to organize a project in a GitHub repository
* how to publish a simple static website
